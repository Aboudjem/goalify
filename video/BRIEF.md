# goalify 3.0 launch promo

## Intent (owner's words)
goalify front-loads everything, then the run happens in a clean context and can work non-stop for
hours or even days with zero interruptions, and it finishes on proof, not a promise.

## Storyboard (pre-approved by the owner; no storyboard review stop)
1. HOOK 0-2.5 s: terminal, Claude prints "Done. All files migrated." Caption "Claude said done."
2. PROBLEM: files still on the old API, failing test. Caption "It wasn't."
3. TURN: goalify mark ignites with stars. Caption "Come back to proof, not a promise."
4. BRIEF: `/goalify migrate to the v2 API`, research + every question up front, a brief file assembles.
5. CONDITION: one line typed after /goal.
6. THE NEW PREVIEW PAGE slides in (faithful to examples/sample-brief.html).
7. NON-STOP: hours/days, zero interruptions, checks ticking.
8. PROOF: receipt with a big green VERIFIED moment.
9. CTA: both install lines + github.com/Aboudjem/goalify.
15 s cut = beats 1, 2, 3, 8, 9.

## Look (owner-approved design language)
Dark #07060f, purple #9b6bff, cyan #2ee6ff, pink #ff3d9a, yellow #ffd23f, green #3dffa8.
Real starfield (depth layers, twinkle, flares, shooting stars with gradient tails), light
glassmorphism (frosted panels, hairline borders, inner top highlight, radii 24 px+), SF Pro /
system stack, generous whitespace, restrained glow, gradient drift on key words. Typographic and
UI-based only: no characters, no sprites. Glass, glow and purple gradients are the brand's own
material (recap-v3.html, sample-brief.html), so they are allowed here despite the generic BANNED list.
